Política de privacidad

Juegos de Reto · Plataforma educativa

Datos utilizados

Para administrar una licencia se utiliza el nombre, correo y, cuando corresponde, información institucional del profesor. Para el acceso estudiantil se utiliza el nombre escrito por el estudiante, el código de clase y la materia autorizada.

Finalidad

Los datos se usan para autenticar usuarios, controlar licencias, mostrar materias contratadas, asociar resultados al profesor correspondiente y mejorar el servicio.

Resultados

Los resultados pueden incluir estudiante, juego, nivel, puntuación y fecha. Se muestran al profesor asociado y al administrador autorizado. No se venden datos personales.

Seguridad y solicitudes

Las contraseñas se almacenan mediante hash seguro y las sesiones tienen duración limitada. El profesor puede solicitar corrección o eliminación de sus datos al administrador.
