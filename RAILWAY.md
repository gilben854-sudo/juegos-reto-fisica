# Subir a Railway — Juegos de Reto para Física

1. Crea cuenta en https://railway.app (con GitHub)
2. Sube esta carpeta a un repositorio de GitHub
3. En Railway: New Project → Deploy from GitHub → elige el repo
4. Root Directory: deja vacío si el repo SOLO tiene saas-platform
5. Start Command: node server-lite.js
6. Generate Domain en Settings → Networking
7. Abre la URL /catalogo.html y /profesor.html

Admin: entra en `/admin.html` con tus credenciales privadas.
La contraseña puede cambiarse desde el panel; no la guardes en este archivo.
